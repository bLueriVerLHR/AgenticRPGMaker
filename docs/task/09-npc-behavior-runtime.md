# Task 09 — Wire NPC behavior system into the runtime (data-driven, D24)

| Field | Value |
|---|---|
| **Goal** | The Behavior strategy seam (Q4/D5, ADR-001) is actually **used by the engine**, not just defined in core: map events can declare a behavior in their JSON data (D24 data-first), core validates it and attaches a `BehaviorComponent`, and the runtime drives it each tick (move/face/say decisions applied). |
| **Why** | Research found the behavior system is **not wired**: `Behavior`/`RuleBasedBehavior` live in core with tests, but no runtime code creates/attaches/drives a behavior — NPCs never use it. The goal axis "增强可定制性（行为接口）" and D24 (AI-authored map data declares NPC behavior) both require this wiring. The Strategy seam already exists (LLM strategy slots in later via the same interface). |
| **Approach** | 1. **core schema** (`schema/map.ts`): add `eventBehaviorSchema` — discriminated union `{ kind: "rule-based", waypoints: Vec2[], speed?, idleSeconds?, triggerSwitch?, faceDirection? }`; `mapEventSchema.behavior?` optional. 2. **core behavior**: add `buildBehaviorFromConfig(config)` factory (validated config → `Behavior`; current: rule-based; future strategies register here) 3. **core scene-graph**: `buildEventEntity` attaches a `BehaviorComponent` with the strategy when `event.behavior` is present. 4. **runtime map-scene**: in `update(dt)` add `updateBehaviors(dt)`: for each entity with a behavior component, build `BehaviorContext` (entity, bus, state, dt, elapsed) and apply the decision — `move` → `transform.translate(dx,dy)`, `face` → `setDirection`, `say` → bus `chat`/dialogue event, `idle` → nothing. 5. **sample**: give the merchant NPC in `samples/maps/town-square.map.json` a small rule-based patrol behavior. 6. **tests**: schema validation (valid/invalid), factory builds rule-based, scene-graph attaches component with strategy, runtime drives a behavior (deterministic). |
| **Files touched** | `packages/core/src/schema/map.ts`, `packages/core/src/behavior/behavior.ts` (+ factory), `packages/core/src/behavior/index.ts`, `packages/core/src/scene/scene-graph.ts`, `packages/core/src/entity/behavior-component.ts` (if needed), `packages/runtime/src/map-scene.ts`, `samples/maps/town-square.map.json`, core/runtime tests, this task doc |
| **Acceptance criteria** | A map event with a `behavior` field gets a driven NPC: its transform changes across ticks deterministically; the sample merchant patrols; schema rejects malformed behavior configs; all QA gate items green; E2E walk-through still passes. |
| **Status** | done |
