# Task 14 — Map transfer: `transfer` command → runtime scene switch

| Field | Value |
|---|---|
| **Goal** | The engine gains map transitions: an event-page `transfer` command publishes a `transfer` gameplay event, and the runtime listens and switches the playable scene to another map (loads the map, rebuilds SceneGraph/interpreter/MapScene, `SceneManager.change`). Fully data-first — AI-authored JSON expresses transfers (`{ "cmd": "transfer", "args": ["house", 2, 3] }`). |
| **Why** | Goal axis "引擎成熟度". An RPG engine must let the player move between maps; today the runtime is single-map (`createGame` fixes one MapScene, `scene` is read-only). This is the fundamental "world is a set of connected maps" capability, and it exercises the open command system (task 08) + SceneManager state pattern (docs/06 §7). |
| **Approach** | **Core (no schema change — `eventCommandSchema` is open `{cmd,args}`):** 1. `events/game-events.ts`: add `TransferEvent { mapId; x?; y?; direction?: "up"|"down"|"left"|"right" }` + `GameEventMap["transfer"]`. 2. `interpreter/commands.ts`: `TransferCommand` (`cmd:"transfer"`, args `[mapId, x?, y?, direction?]`); execute pushes effect `{ kind:"transfer", ... }` and emits the `transfer` event on the bus (core declares intent only — it never loads maps). Register in `builtInFactories`. **Runtime:** 3. `game.ts`: `CreateGameOptions.loadMap?: (mapId: string) => Promise<MapData>` (boot injects the real async loader; tests inject stubs). 4. `createGame` subscribes to the `transfer` event: guard `transferInFlight`; with a `loadMap` available, async-load the target map, rebuild `SceneGraph.fromMap(newMap, {playerPosition, playerDirection})` + `EventInterpreter({ state, bus, scene: newGraph })` + `MapScene({ map: newMap, ..., autoLoad: false, network, tilesets, ... })`, then `sceneManager.change(next)`. Without `loadMap`, log warn and ignore. **Tests:** 5. core — `transfer` command emits the event + records the effect (commands.test.ts). 6. runtime — `createGame` with stub `loadMap`: emit `transfer`, await microtasks, assert `sceneManager.current`'s map id changed and player transform is at the transfer position (game.test.ts). **Sample:** 7. add `samples/maps/house.map.json` (small interior) + a transfer event in `town-square` (an exit door → house) and back; `pnpm validate` green. |
