# Samples

Runnable example maps, projects, tilesets, and generated `www` bundles that prove
the **data → core → runtime → server** pipeline end to end (architecture
[06-architecture.md](../docs/06-architecture.md) §2). Authoring is **data-first**
(D24): these JSON documents are exactly what an AI/agent (or a human) writes; the
editor is archived (D20).

## Layout

| Path                                          | Purpose                                                                                                                                                                                                                                       |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `maps/*.map.json`                             | Sample maps in the versioned map format v1 ([ADR-003](../docs/04-adr/ADR-003.md)); used by the `packages/core` schema test suite and by the packaging phase.                                                                                  |
| `tilesets/*.tileset.json`                     | Sample tilesets in the versioned tileset format v1 ([ADR-003](../docs/04-adr/ADR-003.md)). `placeholder.tileset.json` is the generated placeholder atlas (16 px, 8×8, id `tilesets/placeholder`, matching the atlas generated at build time). |
| `projects/*.project.json`                     | Sample project documents (versioned project format v1) describing which map/tileset/audio assets a game ships.                                                                                                                                |
| `www/` (generated by `scripts/build-www.mjs`) | The portable game package built from these samples (see [samples/README.md](../README.md) and `docs/08-compatibility-checklist.md`).                                                                                                          |

## Running the sample pipeline

The sample `town-square` exercises the full loop:

1. **Author → data** — write/read the game-data JSON directly:
   `samples/maps/town-square.map.json` (two NPCs + a sign, variables,
   switches, two tile layers), `samples/tilesets/placeholder.tileset.json`,
   `samples/projects/town-square.project.json`. `pnpm validate` gates every
   document against the `core` schemas (D24).
2. **Data → runtime (portable www)** — `pnpm build:www` bundles
   `packages/runtime` + `packages/core` + `packages/renderer`, copies the sample
   data into `www/data/`, generates the placeholder atlas image into `www/img/`,
   validates every data file against the core schemas, and runs the banned-API
   smoke check. The result is a self-contained portable game folder.
3. **Runtime → server (optional, D22)** — `pnpm build:deploy` assembles `deploy/`
   with the C++ binary (`agenticrpg-server`) and the built `www/`; the
   server serves the game from one port (local launcher mode) or binds 0.0.0.0 for
   VPS multiplayer mode.

Quick start (single player, portable folder):

```sh
pnpm validate        # data gate (D24)
pnpm build:www
pnpm --dir server exec cmake -B build && cmake --build build  # or pnpm build:deploy
./server/build/agenticrpg-server --www-root www --port 8080
# open http://localhost:8080/
```

Multiplayer: open the game twice with
`?server=ws://<host>:8080/ws&room=demo&name=Player1` / `...&name=Player2`.

## Files

- `town-square.map.json` is the P0 fixture + P5 sample: a small 8×6 map with two
  tile layers, three events (Inn Owner, Merchant, Signpost), variables, and
  switches — every field exercised against the `map` schema in `packages/core`.
- `placeholder.tileset.json` is the tileset document the shipped game uses; the
  atlas PNG itself is generated deterministically at build time.
- `town-square.project.json` is the project manifest (versioned project format v1)
  for the same game — the document that ships in `www/data/project.json`.
